Currículo de Leonardo Santos
Descrição
Este repositório contém meu currículo profissional, desenvolvido no formato Typst, baseado no template modern-resume. O documento destaca minha formação, experiências profissionais, projetos e habilidades como engenheiro eletricista, cientista de dados e desenvolvedor de software e firmware.
Estrutura do Repositório

main.typ: Arquivo principal do currículo em Typst.
fonts/: Pasta com fontes necessárias (ex.: FontAwesome para ícones).
main.pdf: Versão compilada do currículo (gerada com typst compile resume.typ).

Como Compilar

Instale o Typst CLI.
Execute:typst compile main.typ


O arquivo resume.pdf será gerado.

Uso no Typst Web App

Faça upload de resume.typ e da pasta fonts/ no Typst Web App.
Compile diretamente na plataforma para visualizar ou baixar o PDF.

Dependências

Pacote Typst: @preview/modern-resume:0.1.0
Fontes: Roboto, Source Sans Pro
