# Resume Template

## Description
This repository contains my professional resume, written in Typst using the `modern-resume` template. It highlights my education, professional experience, projects, and skills as an electrical engineer, data scientist, and software/firmware developer.

## Repository Structure
- `main.typ`: Main resume file in Typst.
- `fonts/`: Directory with required fonts (e.g., FontAwesome for icons).
- `main.pdf`: Compiled resume output.

## How to Compile
1. Install the [Typst CLI](https://github.com/typst/typst).
2. Run:
   ```bash
   typst compile main.typ
