# MOdelo de Currículo

## Descrição
Este repositório contém meu currículo profissional, escrito em Typst com o template `modern-resume`. Ele apresenta minha formação, experiências, projetos e habilidades como engenheiro eletricista, cientista de dados e desenvolvedor de software e firmware.

## Estrutura do Repositório
- `main.typ`: Arquivo principal do currículo em Typst.
- `fonts/`: Diretório com fontes necessárias (ex.: FontAwesome para ícones).
- `main.pdf`: Versão compilada do currículo.

## Como Compilar
1. Instale o [Typst CLI](https://github.com/typst/typst).
2. Execute:
   ```bash
   typst compile main.typ
